# 🎯 나만의 파이썬 객관식 퀴즈 게임 (Console/CLI)

> **Mission 1-2**: 파이썬 기초 문법, 객체 지향 프로그래밍(OOP), 파일 기반 데이터 영속성(JSON), 그리고 실무형 Git 워크플로우를 직접 구현하며 학습하는 프로젝트입니다.  
> **(보너스 과제 5종 전체 구현 완료: 랜덤 출제, 문제 수 선택, 힌트/감점 시스템, 퀴즈 삭제, 날짜/시간별 플레이 히스토리 기록)**

---

## 📌 1. 프로젝트 개요
* **프로젝트명**: 나만의 파이썬 객관식 퀴즈 게임 (CLI)
* **개발 언어**: Python 3.10+ (외부 패키지 의존성 없이 표준 라이브러리 `random`, `datetime`, `json`만 사용)
* **실행 환경**: Windows / macOS / Linux 터미널 (Console)
* **주요 목표**:
  1. 함수와 클래스(OOP)로 코드를 역할별로 분리하고 모듈화
  2. `state.json`을 통한 데이터 영속성(Persistence) 및 파일 입출력 예외 처리
  3. 공통 입력 검증 헬퍼를 통한 비정상 종료(Crash) 방지
  4. 기능별 세분화된 Git 커밋(15개 이상) 및 브랜치 병합(`feat/play-quiz`) 이력 관리
  5. 5대 보너스 과제(랜덤, 문제 수 선택, 힌트, 삭제, 히스토리) 완벽 지원

---

## 💡 2. 퀴즈 주제와 선정 이유
* **퀴즈 주제**: **흥미진진한 컴퓨터 & IT 상식 퀴즈**
* **선정 이유**:
  * 개발을 처음 시작하는 초심자로서 알아두면 유익하고 흥미로운 컴퓨터 하드웨어(CPU), 인터넷 프로토콜(HTTPS, www), 파이썬 언어의 유래, 디버깅의 의미 등을 퀴즈로 풀며 자연스럽게 IT 기초 지식을 복습하고 상식을 쌓을 수 있도록 선정했습니다.
  * 모든 문제마다 유익한 **힌트(Hint)**가 탑재되어 있어 오답 시에도 배경지식을 쉽게 배울 수 있습니다.
  * 추후 사용자가 원하는 어떤 주제든 메뉴 2번([퀴즈 추가])을 통해 무제한으로 문제를 등록할 수 있습니다.

## 🚀 3. 실행 방법

### 요구 사양
* Python 3.10 이상 설치 필수 (별도의 `pip install` 불필요)

### 실행 명령어
터미널 또는 명령 프롬프트(cmd/PowerShell)에서 프로젝트 디렉터리로 이동한 후 다음 명령어를 실행합니다:

```bash
python main.py
```

## 🛠️ 4. 주요 기능 목록 (필수 + 보너스 5종)

| 번호 | 기능 | 설명 |
|:---:|:---|:---|
| **1** | **퀴즈 풀기** <br>*(보너스 1, 2, 3)* | **① 문제 수 선택**: 풀고 싶은 문제 수를 직접 지정합니다.<br>**② 랜덤 출제**: `random.sample()`로 문제를 무작위로 섞어 출제합니다.<br>**③ 힌트 및 감점 시스템**: `0번`을 입력하면 힌트를 볼 수 있으며, 힌트를 본 문제는 정답 시 50% 점수만 부여됩니다. |
| **2** | **퀴즈 추가** | 문제 지문, 4개 보기, 정답 번호(1~4), 힌트를 입력받아 새 퀴즈를 생성하고 `state.json`에 영구 저장합니다. |
| **3** | **퀴즈 목록 보기** | 등록된 모든 퀴즈의 지문과 힌트 유무를 한눈에 조회합니다. |
| **4** | **퀴즈 삭제** <br>*(보너스 4)* | 등록된 퀴즈 번호를 선택하여 삭제합니다. 실수 방지를 위한 재확인 절차를 거치며, 삭제 결과는 파일에 즉시 반영됩니다. |
| **5** | **점수 및 히스토리** <br>*(보너스 5)* | 역대 최고 점수뿐만 아니라 플레이한 날짜/시간(`datetime`), 푼 문제 수, 맞힌 개수, 힌트 사용 횟수, 최종 획득 점수 이력을 테이블 형태로 출력합니다. |
| **6** | **종료** | 안내 문구를 출력하고 프로그램을 안전하게 종료합니다. |
| **공통** | **철저한 예외 처리** | 문자열 오입력(`abc`), 범위 밖 숫자(0, 9), 빈 엔터 입력 시 프로그램이 죽지 않고 친절한 안내와 함께 재입력을 유도합니다. `Ctrl+C` 입력 시에도 비정상 종료 없이 데이터를 안전하게 저장하고 종료합니다. |

## 💾 6. 데이터 파일 설명 (`state.json`)

* **파일 경로**: 프로젝트 루트 디렉터리의 `state.json`
* **인코딩**: `UTF-8` (한글 깨짐 방지 및 크로스 플랫폼 호환)
* **역할**: 게임이 종료되어도 사용자가 추가/삭제한 퀴즈, 최고 점수, 누적 플레이 히스토리를 영구 보존합니다.
* **손상 복구**: 파일이 없거나 JSON 포맷이 깨진 경우 `try...except` 구문을 통해 손상을 감지하고 안내 메시지 출력 후 기본 퀴즈 5종으로 자동 복원합니다.

* **복제 및 동기화 실습**: 별도 디렉터리로 복제(`git clone`) 후 원격 저장소 푸시 및 원본 디렉터리 가져오기(`git pull`) 실습을 정상 완료했습니다.
