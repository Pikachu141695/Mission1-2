# 🎯 나만의 파이썬 객관식 퀴즈 게임 (Console/CLI)

> **Mission 1-2**: 파이썬 기초 문법, 객체 지향 프로그래밍(OOP), 파일 기반 데이터 영속성(JSON), 그리고 실무형 Git 워크플로우를 직접 구현하며 학습하는 프로젝트입니다.

---

## 📌 1. 프로젝트 개요
* **프로젝트명**: 나만의 파이썬 객관식 퀴즈 게임 (CLI)
* **개발 언어**: Python 3.10+ (외부 패키지 의존성 없이 표준 라이브러리만 사용)
* **실행 환경**: Windows / macOS / Linux 터미널 (Console)
* **주요 목표**:
  1. 함수와 클래스(OOP)로 코드를 역할별로 분리하고 모듈화
  2. `state.json`을 통한 데이터 영속성(Persistence) 및 파일 입출력 예외 처리
  3. 공통 입력 검증 헬퍼를 통한 비정상 종료(Crash) 방지
  4. 기능별 세분화된 Git 커밋(10개 이상) 및 브랜치 병합(`feat/play-quiz`) 이력 관리

---

## 💡 2. 퀴즈 주제와 선정 이유
* **퀴즈 주제**: **흥미진진한 컴퓨터 & IT 상식 퀴즈**
* **선정 이유**:
  * 개발을 처음 시작하는 초심자로서 알아두면 유익하고 흥미로운 컴퓨터 하드웨어(CPU), 인터넷 프로토콜(HTTPS, www), 파이썬 언어의 유래, 디버깅의 의미 등을 퀴즈로 풀며 자연스럽게 IT 기초 지식을 복습하고 상식을 쌓을 수 있도록 선정했습니다.
  * 추후 사용자가 원하는 어떤 주제(영화, 역사, 상식 등)든 메뉴 2번([퀴즈 추가])을 통해 무제한으로 문제를 등록할 수 있도록 유연하게 설계되었습니다.

## 🚀 3. 실행 방법

### 요구 사양
* Python 3.10 이상 설치 필수 (별도의 `pip install` 불필요)

### 실행 명령어
터미널 또는 명령 프롬프트(cmd/PowerShell)에서 프로젝트 디렉터리로 이동한 후 다음 명령어를 실행합니다:

```bash
python main.py
```

## 🛠️ 4. 주요 기능 목록

| 번호 | 기능 | 설명 |
|:---:|:---|:---|
| **1** | **퀴즈 풀기** | 등록된 퀴즈를 1번부터 차례대로 풀고 즉시 정답 여부를 확인합니다. 모든 문제가 끝나면 100점 만점 기준 점수를 계산하고 최고 기록을 자동 갱신합니다. |
| **2** | **퀴즈 추가** | 문제 지문, 4개의 선택지, 정답 번호(1~4)를 차례대로 입력받아 새 퀴즈를 생성하고 `state.json`에 영구 저장합니다. |
| **3** | **퀴즈 목록** | 현재 프로그램에 등록된 모든 퀴즈의 문제 지문과 총 개수를 번호별로 한눈에 조회합니다. |
| **4** | **점수 확인** | 현재까지 기록된 최고 점수를 확인합니다. 아직 풀지 않은 경우 안내 메시지가 표시됩니다. |
| **5** | **종료** | 안내 문구를 출력하고 프로그램을 안전하게 종료합니다. |
| **공통** | **철저한 예외 처리** | 문자열 오입력(`abc`), 범위 밖 숫자(0, 9), 빈 엔터 입력 시 프로그램이 죽지 않고 친절한 안내와 함께 재입력을 유도합니다. `Ctrl+C` 입력 시에도 비정상 종료 없이 데이터를 안전하게 저장하고 종료합니다. |

## 💾 6. 데이터 파일 설명 (`state.json`)

* **파일 경로**: 프로젝트 루트 디렉터리의 `state.json`
* **인코딩**: `UTF-8` (한글 깨짐 방지 및 크로스 플랫폼 호환)
* **역할**: 게임이 종료되어도 사용자가 추가한 퀴즈와 달성한 최고 점수를 영구 보존하는 데이터베이스 역할.
* **손상 복구**: 파일이 없거나 JSON 포맷이 깨진 경우 `try...except` 구문을 통해 손상을 감지하고 안내 메시지 출력 후 기본 퀴즈 5종으로 자동 복원합니다.

### 데이터 스키마 (JSON Schema 예시)
```json
{
    "quizzes": [
        {
            "question": "파이썬(Python) 프로그래밍 언어의 이름은 어디에서 유래되었을까요?",
            "choices": [
                "아프리카에 서식하는 거대한 비단뱀",
                "영국의 전설적인 코미디 쇼 '몬티 파이선 비행 서커스'",
                "그리스 신화에 등장하는 거대한 뱀 괴물",
                "창시자 귀도 반 로섬이 기르던 애완 앵무새"
            ],
            "answer": 2
        }
    ],
    "best_score": 80
}
```

## 🌿 7. Git 브랜치 전략 및 이력
* **브랜치 활용**: `feat/play-quiz` 브랜치를 분기하여 퀴즈 풀기 및 채점 로직을 개발하고, 검증 완료 후 `main` 브랜치에 안전하게 병합(`merge --no-ff`)했습니다.
* **커밋 원칙**: 기능 단위로 의미 있는 커밋 메시지 접두사(`Feat:`, `Chore:`, `Docs:`)를 사용하여 작업 과정을 투명하게 기록했습니다.
* **복제 및 동기화 실습**: 별도 디렉터리로 복제(`git clone`) 후 원격 저장소 푸시 및 원본 디렉터리 가져오기(`git pull`) 실습을 정상 완료했습니다.
